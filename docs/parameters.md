# Parameters

All the parameters of the pipeline, generated from the parameter schema (`nextflow_schema.json`) used to validate them when the pipeline starts. See the [usage](usage.md) page for how the parameters work together, e.g. which reference each deconvolution tool uses.

The parameters can be given on the command line (e.g. `--meth_atlas`) or in a parameters file (`-params-file params.yaml`). Parameters hidden in the help message (`--help`) are not listed.
